# 🎨 拼豆像素图转换器

将任意图片一键转换为拼豆（Perler Bead / 熔豆）像素图纸的在线工具。纯前端实现，图片不会上传到任何服务器。

## ✨ 功能特性

- **图片转拼豆图** — 自动匹配拼豆颜色编号，生成圆润的豆豆效果图
- **多种钉板尺寸** — 52×52（14cm 钥匙扣）、78×78（21cm 立牌）、104×104（28cm 挂画）、120×120（33cm 大幅），也支持 16~200 豆自定义
- **色彩调节** — 亮度 / 饱和度 / 对比度滑块，实时预览
- **抖动算法** — 无 / Floyd-Steinberg / 有序抖动，让色彩过渡更自然
- **颜色数限制** — 可限制为 8/12/16/24/32/48 色，颜色越少越简洁
- **编辑模式** — 点击 / 拖动替换单个豆的颜色，支持撤销
- **背景色标记** — 可将颜色标记为背景，导出时不显示（支持全选 / 清除 / 自动识别）
- **高清图纸导出** — 四边行列编号、每格标注颜色编号、每 5 格网格线加粗、底部颜色统计
- **移动端适配** — 手机浏览器可直接使用，带悬浮小预览窗
- **完全本地运行** — 无需联网、无需安装，打开 HTML 文件即可使用

## 🚀 使用方法

### 在线 / 本地打开

**PC 端：** 直接双击打开 [`拼豆图片转换器.html`](./拼豆图片转换器.html) 即可使用。

**手机端：** 将 HTML 文件保存到手机后，用浏览器打开（如夸克浏览器：我的 → 我的手机 → 最近文件 → 拼豆图片转换器.html）。

### 基本流程

```
上传图片 → 调整参数 → 开始转换 → 编辑调整 → 导出图片
```

1. **上传图片** — 点击上传区域或拖拽图片（支持 JPG / PNG / GIF / WebP，建议不超过 2000×2000 像素）
2. **调整参数** — 选择钉板尺寸、色彩、抖动算法、最大颜色数等
3. **开始转换** — 点击「✨ 开始转换」按钮
4. **编辑调整**（可选）— 进入「🖌 编辑模式」，点击或拖动画布替换单个豆的颜色
5. **导出图片** — 点击「📥 导出图片」，生成带编号的高清图纸

> 详细说明请参见 [`使用教程.txt`](./使用教程.txt)
